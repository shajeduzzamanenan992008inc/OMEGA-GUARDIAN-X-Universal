# Security policy

## Scope

This policy applies to the OMEGA GUARDIAN X alpha source and its official distribution artifacts.

## Reporting a vulnerability

Do not publish credentials, private repository contents, or an unpatched exploit in a public issue. Until a dedicated security contact is published, report suspected vulnerabilities privately to the project owner through the private channel by which you received this software. Include the affected version, impact, reproduction steps, and a minimal proof of concept that does not expose real secrets or customer data.

## Release expectations

The alpha is not independently audited and must not be used as a production security boundary. Security-sensitive changes require regression tests and review. Release artifacts should be signed before public commercial distribution.
