# OMEGA GUARDIAN-X UNIVERSAL - Brand Pack
Creator & Builder: Shajeduzzaman Enan

Ultra-animated deep-space identity: glowing Omega core, three orbiting modules (NEXUS PRIME / SELF EVOLUTION / GUARDIAN-X), HUD frame, nebula, glitch title.

## Inside
- logo/ - omega-logo.svg (animated, transparent) + PNG 1024; omega-logo-bg (SVG + PNG + MP4); omega-icon (SVG, .ico, favicons 32-512)
- banner/ - banner-1280x640 (SVG, PNG, MP4, GIF); social-preview-1280x640.jpg (under 1 MB); readme-banner-1600x500 (SVG, PNG, MP4)
- readme-kit/ - divider, 6 section headers, 4 status badges, footer (animated SVG) + README-snippet.md

## Use in the repo
1. Copy the banner and readme-kit files into an assets/ folder in the repo.
2. Paste README-snippet.md at the top of README.md.
3. GitHub -> Settings -> Social preview -> upload banner/social-preview-1280x640.jpg.
4. Use logo/omega-icon.ico and the favicon PNGs for apps and sites.

## Notes
- All text is outlined, so no fonts are needed. SVG animation plays in browsers and GitHub READMEs; use the GIF/MP4 where SVG animation is blocked.
- Every loop is 8.5 s, so the MP4/GIF loop without a jump.
- Outline fonts: Montserrat and Anonymous Pro (both OFL).
