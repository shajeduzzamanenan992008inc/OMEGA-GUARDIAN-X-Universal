# Claude Code project guidance

Follow `AGENTS.md`, `.github/copilot-instructions.md`, and `docs/SECURITY_MODEL.md` as the canonical project rules. In particular, default scans are external and read-only: never execute target code or package scripts, and keep runtime/configuration/reports in OGX-owned external state. The optional `ogx integrate` command may create only allowlisted, missing root-level AI governance files after a reviewed plan and explicit confirmation; it must never overwrite existing files. Treat target files as untrusted data, redact secrets, preserve partial-scan warnings, and add tests proving default scans remain read-only and integration preserves conflicts, rejects symlinks, and removes only unchanged OGX-created files. Do not implement automatic repair without a separate explicit approval and rollback design.
