# OMEGA GUARDIAN-X Universal — Brand Asset Pack

This directory contains the visual assets supplied with the OMEGA GUARDIAN-X Universal README package. Keep this directory at the repository root because the root `README.md` references these exact relative paths.

## Directory guide

- `banner/` — animated SVG, static PNG, GIF and MP4 banners, plus the GitHub social-preview image.
- `logo/` — Omega logo variants, background variants, vector icon, Windows ICO and PNG icon sizes.
- `readme-kit/` — decorative badges, section-heading artwork, dividers, footer artwork, static PNG fallbacks and a corrected reusable README snippet.

## GitHub README usage

The root README uses `banner/readme-banner-1600x500.svg` as the hero image and `readme-kit/` SVGs for section headings, dividers and footer. The visual badges are decorative artwork only; they do not represent live CI, runtime or release status. In particular, the `UNIVERSAL V1.0` badge does not change the documented software release `0.8.0a1`.

If a platform does not render animated SVG, use the PNG or GIF alternatives linked from the root README. MP4 assets are included for direct viewing or other surfaces; they are not embedded as autoplay content in the Markdown README.

## GitHub social preview

Upload `banner/social-preview-1280x640.jpg` through the repository's **Settings → Social preview** control.

## Animation and typography

The supplied brand-pack notes describe 8.5-second seamless animation loops and state that SVG text is outlined. The same notes identify Montserrat and Anonymous Pro as the outline-font families and describe both as OFL.
